`SELECTED WORK`

**[changeover](https://github.com/brunohart/changeover)** — An open commitment boundary for cinema exhibition. An agent holds the seat for a stated, irrevocable window and hands the customer back to the exhibitor's own checkout, with the seats still there. Specification-first: the spec, its schemas and three golden digests were committed before a line of implementation existed, so the conformance suite can never be a program agreeing with itself. <sub>`TYPESCRIPT` · `POSTGRES` · `MCP`</sub>

**[theatrical](https://github.com/brunohart/theatrical)** — Type-safe SDKs, CLI tools, UI components, a real-time event bridge and analytics for cinema platform APIs. One API surface across three languages. <sub>`TYPESCRIPT` · `C#` · `PYTHON`</sub>

**[telecine](https://github.com/brunohart/telecine)** — A public broadcast network for public-domain cinema. Clock-synced channels, no server, no algorithm. You don't press play; you tune in. <sub>`ASTRO` · `STATIC`</sub>

**[cinema-ops-platform](https://github.com/brunohart/cinema-ops-platform)** — A local, fully-proven data platform for cinema exhibition data. Four unlike sources, an append-only bronze layer, a governed gold layer, and an agent tool set with no personal-data field anywhere in it. <sub>`PYTHON` · `DUCKDB`</sub>

`THE THROUGH-LINE`

> Agentic commerce is winning the path to purchase. Nobody yet owns the path to meaning.
>
> The agent can book the ticket. It can't manufacture the anticipation.

Cinema's operational layer is being won right now — cloud migrations, agentic checkout, platform consolidation. The cultural layer is the frontier: the ritual, the anticipation, the reason someone chooses the 70mm print at the old room over the convenient screening down the road. I build at the seam between the two, and I think the seam belongs to exhibitors rather than to whoever inserts themselves between a cinema and its audience.
